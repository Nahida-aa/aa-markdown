# aa-markdown

一个用 Rust 实现的 Markdown 库，同时也是面向 TypeScript/JavaScript 开发者的 Rust 实战教程。

本仓库有两条目标：

- 最终得到一个可使用、可测试、可扩展的 Markdown 库。
- 让学习者仅根据行为规范、测试和提示，从零实现一个相同或兼容的库。

## 学习方式

学习过程以教程为准，核心代码由学习者亲自实现。每个阶段都会先说明：

1. 要解决的问题。
2. 对外行为和 API 约定。
3. 对应的 TypeScript/JavaScript 思路。
4. 验收测试。
5. 可选提示和参考实现方向。

不要先阅读最终实现再照抄。先根据规范完成自己的实现，再用测试和参考实现进行对比。
